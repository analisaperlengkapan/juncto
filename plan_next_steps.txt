User wants us to migrate missing features from the legacy app to the rust app.

Based on our exploration, the following legacy React features don't seem to have direct equivalents in the Rust app yet:
- Audio Level Indicator (`react/features/audio-level-indicator`)
- Remote Control (`react/features/remote-control`)
- Face Landmarks (`react/features/face-landmarks`)
- Embed Meeting (`react/features/embed-meeting`)
- Transcribing (`react/features/transcribing`)

Since this is a full migration, we should pick at least one or two prominent missing features to implement completely (frontend UI, state management, backend signaling if needed, and tests).

Let's pick:
1. "Audio Level Indicator": We can add a visual indicator on the `VideoGrid` items to show if a user is speaking or their audio level. Since `speaker_stats` exists and there is `is_speaking` in `media.rs` and `state.rs`, we can enhance the `Participant` struct and UI to display an Audio Level Indicator.
2. "Embed Meeting": Add a dialog or button to copy the iframe embedding code or meeting URL easily, similar to `EmbedMeetingDialog.tsx`.
3. "No Audio Signal": Detect if a user is speaking but muted or has no audio input, and show a toast warning.

I will plan out adding the Embed Meeting Dialog and Audio Level Indicator as they are prominent features.
